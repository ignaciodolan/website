Building a voice-to-Obsidian pipeline that actually understands you

Jan 9, 2026

The v1 recap

A few weeks ago I built a system to turn voice memos into structured Obsidian notes automatically. The flow: record a voice memo on iPhone → share it via Shortcuts → Tailscale sends it to a Flask server running on my Mac → Whisper transcribes it → GPT-4o-mini organises it into sections → the note lands in Obsidian.

It worked. But after using it daily, four problems became obvious.

Problem 1: Whisper doesn't know my vocabulary

Whisper is impressive, but it has no idea that I run a local restaurant called Guarango, or that I work with a company called Big Fidelity, or that I use Tailscale and Embat daily. So the transcripts would come out like this:

"I was talking to Tashforce about the lack integration at Big Filiety…"

Which should have been:

"I was talking to Task Force about the Slack integration at Big Fidelity…"

Every wrong word meant lost context when GPT tried to make sense of it.

The fix: a living vocabulary note in Obsidian

Whisper has an initial_prompt parameter that primes the model with context before it starts. Instead of hardcoding a list in a config file, I created a note at Brain dump/Vocabulary.md inside my Obsidian vault. The pipeline reads it on every run and passes the contents as initial_prompt. To add a new word I just open Obsidian, edit that note, and the next recording picks it up. No code changes, no redeploy.

Problem 2: too many todos

The original GPT prompt said: "extrae tareas concretas y accionables mencionadas o implícitas en el audio."

The word implícitas was doing a lot of damage. GPT was turning every idea, observation, and passing thought into a - [ ] checkbox. A brain dump would end up with 12 todos, half of which were things I was just thinking out loud about, not commitments.

The fix: explicit intent verbs only

The new instruction is strict: only things I explicitly committed to become todos: phrases like "tengo que", "necesito", "voy a", "hay que". Everything else goes into Ideas or Oportunidades where it belongs.

Problem 3: no way to debug transcription issues

When the note came out wrong, there was no way to know if the problem was the transcription or the GPT structuring. The raw Whisper output was thrown away after processing.

The fix: transcript at the bottom

Every brain dump note now ends with a ## Transcript section containing the raw Whisper output verbatim. If something looks off in the structured note, I scroll down and see exactly what Whisper heard. Correct transcript + wrong structure = prompt issue. Garbled transcript = add the word to Vocabulary.md.

What the note looks like now

# Brain Dump - 2026-01-09

## Estado emocional
enfocado

## Prioridad del día
Definir integración de Slack con Big Fidelity

## Ideas
- Explorar dashboards para Guarango

## Todos
- [ ] Llamar a Task Force sobre la integración
- [ ] Revisar métricas de Embat esta semana

## Transcript
Hoy hablé con Task Force sobre la integración de Slack con Big Fidelity...

Problem 4: tweaking the prompt required a code change

Every time GPT structured something wrong (wrong tone, wrong section, missing nuance), fixing it meant editing structure.py, restarting the server, and hoping the change worked. That feedback loop was too slow for something you use every day.

The fix: prompt lives in Obsidian

The GPT system prompt now lives at Brain dump/Prompt.md in the vault. The pipeline reads it on every run, same as Vocabulary.md. Open the note, change a line, save. The next recording uses it immediately.

The hardcoded prompt in code stays as a fallback. If Prompt.md doesn't exist, it still works. If it does exist, Obsidian wins.

The full set of live-editable config is now:

NoteControls
Brain dump/Vocabulary.mdWords Whisper should recognise correctly
Brain dump/Prompt.mdHow GPT structures and interprets the transcript

No code changes needed for either. The pipeline just reads them on every run.

What's next

  • Smarter pending todos. Age out unchecked todos after a few days instead of carrying them forward indefinitely
  • Weekly digest. A Sunday note that summarises the week's ideas and patterns across all daily dumps
  • Language detection. I sometimes mix Spanish and English mid-sentence. Telling GPT that explicitly should help it handle both

Built with Python, Whisper, GPT-4o-mini, Flask, Tailscale, and Obsidian CLI.
